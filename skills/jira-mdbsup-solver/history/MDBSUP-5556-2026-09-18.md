# MDBSUP-5556 — frontlogs2-adtech-kafka: downscale-broker, unregisterBroker на уже deregisterнутом брокере

**Дата:** 2026-09-18
**Кластер:** frontlogs2-adtech-kafka (a12b488e-3584-4a0e-bdf5-983be4e29ed0), downscale kc
**Операция:** delete_hosts 6f50934b-2735-47f3-9124-5f978bc88aa2, брокер 21005 (5.kc)

Задача оператора `kafka.downscale-broker` парилась на `unregisterBroker` — брокер уже был
deregisterнут (KRaft после удаления инстанса из облака), исключение не считалось успехом.
Хост и storage к моменту разбора уже отсутствовали в облаке, host_state-строки не было —
дрейн завершён (0 партиций на 21005 из 101 топика).

Лечение: op_stop задачи → get_result перевёл операцию in_progress → failed (attempts_left=0,
самосхождения до done не случилось) → закрытие SQL (done + finished_ts). Withdraw не нужен.
