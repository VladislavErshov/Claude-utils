# MDBSUP-5521 — 2026-09-17 — update_user падает на невалидном ACL CLUSTER/* (mdb-data не валидирует resourceName)

- **Кластер:** `search-vkpeople` (mdb10125) `a596f57d-65fa-49f9-9ee4-3861839f733b` — 3 брокера (ic/kc/rc) + 3 контроллера + cruise
- **Операция:** `update_user` `d3e84ee3-f198-4113-a672-c3beb2f99cd9` — failed + in_processing=true, очередь заблокирована
- **Суть:** в API-запросе пришло правило `{resourceType: CLUSTER, resourceName: "*"}`; mdb-data записал его в operation_model без валидации, Kafka отверг весь батч createUser («The only valid name for the CLUSTER resource is kafka-cluster»). Правило не применилось нигде — ни в Kafka ACL, ни в permissions БД, поэтому UI его не показывал; чинить на кластере было нечего
- **Фикс:** только закрытие операции DML (`UPDATE operations SET status='done', in_processing=false ...`); заявителю — повторить правку без CLUSTER/*
- **Баг продукта:** валидация resourceName при resourceType=CLUSTER в mdb-data — [MDBDEV-3458](https://jira.vk.team/browse/MDBDEV-3458)
- **Закрытие:** публичный комментарий + разбор для Developers (id 53334198), тикет закрыт
