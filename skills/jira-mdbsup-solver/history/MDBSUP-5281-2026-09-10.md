# MDBSUP-5281 — Kafka trg-195060-dwh: брокеры UNAVAILABLE (disk 100%), ресайз упал на старте

- **Дата:** 2026-09-10
- **Кластер:** trg-195060-dwh (`a8261a9a-f8d8-46fd-b744-7b3cd3c3a9f9`), project datatransfer, prod
- **Операция:** modify_cluster `34343bf6-c48b-4b55-9f2b-e2a4c7220fcd` (ресайз диска брокеров 190→250G)

## Суть

- Пользователь запустил ресайз диска из-за заполнения. Операция упала на шаге
  `start_resize_kafka_workflow` с ошибкой «Couldn't find workflow in processing to sync status» —
  workflow в Temporal **не создавался вообще** (по operationId пусто; последние workflow по кластеру — 2026-09-04).
  Операция осталась `failed` + `in_processing=true` и блокировала новые операции.
- Все 3 брокера (kc/pc/uc) UNAVAILABLE: `/mnt/data` (180G) забит на 100%, контейнер kafka-broker
  не стартует (`failed`, OCI runtime error). Контроллеры живы.

## Причина disk full

Данные, не мусор: топик `trg-195060-dwh.billing.transaction_groups` (RF=3, на каждом брокере
все 10 партиций × ~16G ≈ 155G) + `transaction` (~25G). Чистить руками нельзя.

## Фикс

- Операция закрыта DML: `status='canceled', in_processing=false, finished_ts=now()` (одобрено пользователем;
  статус `canceled` вместо `done` — ресайз реально не выполнялся). Ретрая не было (Temporal пуст, attempts_left=0).
- **Грабля:** упавшая операция успела записать целевую конфигурацию — в `db_cluster_version`
  (последняя строка, `cluster_params->>'diskGb'` верхнеуровневый ключ, НЕ в kafkaParams) уже стояло
  250 → UI не давал запустить resize на 250. Правка: `jsonb_set(cluster_params,'{diskGb}','249')`
  для строки 291096 (одобрено пользователем), после чего resize на 250 запускается.
- Дальше — перезапуск ресайза 190→250 через UI mdb-data пользователем; расширение диска не требует живого брокера.

## Уроки

- Ошибка «Couldn't find workflow in processing to sync status» = workflow не создался на старте
  (start-фаза), а не потерялся в ретраях — в Temporal по operationId будет пусто. Разовый сбой
  processing'а при старте workflow; правка — просто закрыть операцию и перезапустить.
