# MDBSUP-5280 — extdbpu: «аномальный» размер партиции 35 oneme_core_NetBackEvents (~1 ТБ)

Дата: 2026-09-10. Kafka, ns infra, кластер `94bed650-7adf-4b78-9640-37a311033e65`
(`extdbpu`, criticality A). Без операций — чистая диагностика данных.

CC UI показывал Disk=1020575 MB у партиции 35; автор счёл метрику некорректной.
Проверка по факту: метрика корректна — на диске ~1048 GB на каждой из 3 реплик,
ретеншн (60 ч) работает. Корневая причина — горячий ключ `0x00`×8 (87% сообщений
партиции): дефолтный int64-ключ продюсера всегда попадает в партицию 35. Фикс на
стороне продюсера; правки кластера не нужны.
