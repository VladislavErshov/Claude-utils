# MDBSUP-5216 — kafka-news-snapshots (news): зависшая sys_update_cluster (оператор `kafka.update`)

- **Кластер:** `9974b16f-f2d1-4b29-a237-a9753d1f3700`, fullQueue `kafka-news-snapshots-news-kafka.news.db.production.mdb.prod`, ns infra.
- **Суть:** операция `de275607` sys_update_cluster (образ 2.3.2→2.4.4) от 07.09 висит >24ч. Temporal по operationId **пуст — это норма**: sys_update_cluster исполняет оператор one-cloud-ops (задача `kafka.update`), get_result ждёт её исчезновения из `operators.kafka.tasks`. Задача из оператора исчезла (следа нет ни в tasks, ни в taskinfos/persisted — историю оператор не хранит), но операция замерла `in_progress/in_processing=false` — TASK_ABSENT никто не увидит, закрытие только SQL. Хосты на kafka 3.8.0 — обновление не перекатилось вовсе, `db_cluster_version` (2.3.2) фактическая, не трогать. До 17:39 08.09 были failed hosts — вероятная причина стоянки задачи.
- **Фикс:** UPDATE operations → **canceled** (08.09 17:57); обновление перезапустить владельцу заново через UI.
