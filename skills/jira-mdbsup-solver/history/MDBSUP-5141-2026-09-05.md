# MDBSUP-5141 (2026-09-05) — chathub: create_cluster упала, ec-хост изолирован по IPv4

Кластер `fbc3e4b4-91f9-4f31-aad4-cca10d387093` (mdb10263, Kafka 3.8), операция create_cluster
`0f88a303-e690-4a1b-b11e-109692dfb61a` упала «service is in STARTING UNAVAILABLE». Корень:
v4 между ec (M100) ↔ kc/pc дропается в обе стороны, v6 жив → ec-контроллер в candidate,
ec-брокер в crash-loop «unable to register» (~65 с). Кворум 2/3 держат pc+kc. Тот же паттерн,
что MDBSUP-5137 накануне — похоже, один сетевой инцидент M100 с новыми ec-хостами.
