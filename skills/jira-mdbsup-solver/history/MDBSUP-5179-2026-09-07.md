# MDBSUP-5179 — vk-video-dscv: диски 100% на брокерах rc/uc, чистка протухших test/stage-топиков

Дата: 2026-09-07. Кластер `vk-video-dscv` (`53ea5f26-25b2-4595-ae8f-e161f22d1a7b`),
Kafka KRaft, брокеры `1.broker.vk-video-dscv-mdb10084-kafka.{rc,uc,kc}.one-infra.ru`.

Суть: rc/uc упали `No space left on device` (/mnt/data 1000G = 100%), kc жив. Квоты
на ресайз диска у юзера нет → чистка руками. Диск забит топиками
`unisearch_vk_video_dscv_generic_vk_sessions_{test,stage}` (~868 GB на брокера),
все данные старше retention.ms=7 суток (продюсер встал 17.08, брокеры лежали —
ретеншен-клинер не работал). Чистка по дежурной доке: `find . -type f -mmin +10080
-delete` по 64 партициям с сохранением `partition.metadata` + `leader-epoch-checkpoint`
на каждом хосте → 100% → 14% (869/867 GB), брокеры подняты пользователем.
