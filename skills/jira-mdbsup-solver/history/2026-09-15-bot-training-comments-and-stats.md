# 2026-09-15 — Комментарии для Developers (датасет для бота) + статистика сапы

Задача: во все решённые MDBSUP по Kafka (25.08–15.09) написать комментарии для обучения
бота, видимые только роли Developers, + собрать статистику типов проблем.

## Что сделано

- **68 тикетов** получили комментарий-разбор: шаблон plain-text `ПРОБЛЕМА / ДИАГНОСТИКА /
  РЕШЕНИЕ / ПРОВЕРКА / ОСТАТОК`, visibility `{"type":"role","value":"Developers"}`.
  Формат и доставка — в text-writer, раздел «Jira (комментарий для Developers)».
- Существующие пользовательские комментарии не трогали (те — для заявителей, наши — для бота).
- Delivery: REST `POST/PUT https://jira.vk.team/rest/api/2/issue/<KEY>/comment` (Bearer-токен
  из env MCP-сервера jira в opencode.json). MCP-инструмент visibility не поддерживает.
  Python urllib падает на SSL (корп-цепочка) — слать curl'ом из файлов JSON.
- Черновики комментариев генерировались из history-файлов этого скилла + скиллов-инспекторов
  (kafka-cluster-inspector, kafka-host-inspector, kafka-metrics-investigator,
  kafka-reassign-partitions, db-worker), партиями по ~10.

## Финальная статистика (структура согласована с пользователем)

### Стопперы операций — 49 (72%)
- Проблемы оператора one-cloud-ops — 12 (24% стопперов): задача исчезла/финализация
  не доехала ×6 (4915, 4932, 5051, 5103, 5216, 5253); precondition не сходитcя — JMX
  меж-ДЦ/модель ×4 (4895, 4899, 5304, 5328); ждёт reassign — drain/дедлок CC ×2 (5177, 5269)
- Инфраструктура облака/сеть — 8 (4867, 4937, 4938, 4942, 5127, 5137, 5141, 5154):
  IPv4-изоляция ec, cloud-апдейт, volumes, LOST_MINION
- Кворум KRaft — 7 (4970, 5093, 5063, 5219, 4939, 4833, 5270): stale voters ×4,
  лидер/зомби ×2, вечные выборы ×1. Корень починен в продукте (перерендер voters +
  пересчёт controllerDcs при add/delete_hosts) — массово не должен повторяться
- Рассинхрон БД/конфигов mdb-data — 7 (4832, 4892, 4925, 4936, 5007, 5068, 5226)
- URP/призрачные реплики → PREFAIL → блок операций — 4 (4994, 5158, 5159, 5203)
- CC создание/health — 3 (5237, 5288, 5289)
- Диски (stray + утечка fd, 100%) — 2 (5179, 5279) — юзеры решают сами через
  retention/ресайз, когда операции разблокированы
- Не хватило таймаута — 2 (4771, 5281); ACL=ANY — 2 (5233, 5264);
  modify не рестартит мёртвые хосты — 1 (5135, исправлено); квота — 1 (4898)
