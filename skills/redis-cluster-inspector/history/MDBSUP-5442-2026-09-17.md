# MDBSUP-5442 (2026-09-17): dual-stack Redis — CLUSTER SLOTS отдаёт IPv6

Кластер: ysrecommend (87873d27-802b-48e7-bbb2-b576a2db0ce1), проект mdb258, шардированный,
3 шарда × 3 ДЦ (kc/rc/dc), Redis 7.0.15, queue `ysrecommend-mdb258-redis`.
Заказчик переезжает со своего Redis в MDB, его сервисы v4-only, а `CLUSTER SLOTS`/MOVED
возвращали IPv6 (gossip-адреса) — блокер миграции. Просили оценить `cluster-announce-ip`.

## Решение (вариант А, канон платформы)

`cluster-announce-hostname` уже стоял на всех нодах, но `cluster-preferred-endpoint-type=ip`
→ в выдаче «сырой» v6. Фикс:

1. На всех 9 нодах: `config set cluster-preferred-endpoint-type hostname` + `config rewrite`
   (мгновенный эффект, SLOTS/MOVED начинают возвращать FQDN; DNS имеет и A, и AAAA —
   v4-only клиент берёт A).
2. Фиксация, чтобы не слетело:
   - **PMS `zen.redis.conf`** (ключ `ysrecommend-mdb258-redis.clouds`, ns=infra) — append
     строки `cluster-preferred-endpoint-type hostname`. Цепочка рендера: `/etc/redis/redis.conf.j2`
     вставляет `{{ pms('zen.redis.conf') }}` **дословно** в конец redis.conf → confp --oneshot
     параметр сохраняет (проверено).
   - **Прод-БД `cluster_to_template`** (строка с `template_type='redis_cluster_config'`) —
     append той же строки в `template_body`: это шаблон, из которого mdb-data/UI регенерирует
     `zen.redis.conf` при кластерных update'ах. Без правки слетело бы при первом update через UI.
3. `cluster-announce-ip <v4>` (вариант Б) возможен, но рискованнее: gossip-эндпоинты всех нод
   меняются на v4, cluster bus + репликация переезжают на v4 (нужна межДЦ v4-связность 6379/16379).

## Грабли/находки

- Docker daemon подвис (`docker ps` ханг) → psql из контейнера недоступен. Fallback:
  `python3 + psycopg2` напрямую на туннель localhost:53480 — работает.
- MCC-интроспекция по кластеру: `%ysrecommend%` находит только по одному хосту на шард-ДЦ
  (`1.shard{1..3}-db.ysrecommend-mdb258-redis.{kc,rc,dc}`); полные 9 нод собираются перебором ДЦ
  (`instances` без `-c <dc>` ищет только в дефолтном облаке).
- `CLUSTER SLOTS` при hostname-режиме отдаёт FQDN первым элементом, v6 остаётся в metadata-поле
  `ip` — это норма формата Redis 7.0, клиенты берут endpoint.
