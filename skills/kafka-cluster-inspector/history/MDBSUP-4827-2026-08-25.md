# MDBSUP-4827 — Миграция ноды cruise-control из HC в EC (onemekafkaauth38-oneme-kafka)

- Дата: 2026-08-25
- Кластер: `8c808b3f-a640-4410-acbb-055b85ba0495` (onemekafkaauth38-oneme-kafka, Kafka, ns infra, domain one-infra)
- Хост: `1.cruise.onemekafkaauth38-oneme-kafka.hc.one-infra.ru`

## Суть

Перенос Cruise-control ноды из HC в EC. Выполнено удаление CC-ноды из облака HC + чистка прод-БД.

## Шаги (выполнено)

1. **Stop сервиса** (облако HC — обязательно `mcc -c HC`, без `-c` EntityNotFoundException!):
   `mcc -c HC -n infra stop cruise.onemekafkaauth38-oneme-kafka` → FINISHED/STOPPED.
2. **Withdraw сервиса**: `mcc -c HC -n infra withdraw cruise.onemekafkaauth38-oneme-kafka`
   — висел в «Waiting for service ID to be freed at SID broker» ~2 мин, потом сервис исчез (EntityNotFoundException = success).
3. **Withdraw storage**: `mcc -c HC -n infra withdraw onemekafkaauth38-oneme-kafka.oneme.db.dev.mdb.prod/cruise`
   - Грабля 1: пока сервис держит replicas=1, storage withdraw падает `ServiceValidationException: Cannot withdraw storage used by services`.
     `mcc rescale ... 0` не работает (`New replicas is invalid: 0`). Решение — withdraw именно ПОСЛЕ withdraw сервиса.
   - Грабля 2: подтверждение `9 mod 6` — ответ подавать через stdin: `echo "3" | mcc ... withdraw`.
4. **Прод-БД** `backstage_plugin_mdb` (port-forward 53480):
   ```sql
   DELETE FROM host_state WHERE cluster_id='8c808b3f-a640-4410-acbb-055b85ba0495'
     AND host='1.cruise.onemekafkaauth38-oneme-kafka.hc.one-infra.ru';               -- DELETE 1
   UPDATE db_cluster_version
   SET cluster_params = jsonb_set(cluster_params, '{kafkaParams}',
         (cluster_params->'kafkaParams')::jsonb - 'cruiseControl'::text),
       update_ts = now()
   WHERE cluster_id='8c808b3f-a640-4410-acbb-055b85ba0495'
     AND cluster_params->'kafkaParams' ? 'cruiseControl';                             -- UPDATE 9 (все строки кластера)
   ```

## Итог

- Сервис и storage cruise в облаке HC выведены (EntityNotFoundException по обоим).
- host_state: cruise-хост удалён.
- db_cluster_version: ключ `kafkaParams.cruiseControl` удалён целиком (не смена dc!) во всех 9 строках кластера, has_cruise=f everywhere.

## Грабли/заметки

- Облако задаётся `-c HC` — по умолчанию mcc идёт в другой cloud и сущность «не находит».
- DML в psql через docker exec heredoc молча не применяется — только `docker cp` + `psql -f`.
- На PG 14: `jsonb_expr - 'literal'` даёт `operator is not unique: unknown - unknown`;
  лечится явными кастами `(x->'k')::jsonb - 'key'::text`.
- Для кластера в one_cloud_meta осталась запись cruise-control-service (fake_id 9119) — чистка НЕ нужна (подтверждено пользователем), не трогать.
