## Главный вывод

Связь **mdb-data (remaining-contract) ↔ processing master** работает end-to-end через API:
- POST/DELETE → 202 → операция → workflow → save в обе стороны (add нового хоста/ДЦ и
  diff-удаление ДЦ из db_cluster_version);
- converge-семантика на уже поднятый хост (skip child, save доводит БД);
- guard min-3 и коды ответов корректны.
