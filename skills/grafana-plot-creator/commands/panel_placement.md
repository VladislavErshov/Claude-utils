# Размещение панелей в Grafana dashboard JSON

Структура дашборда и правила `gridPos`. Боевой пример — `/Users/vl.ershov/Downloads/grafana2.txt`.

## Сетка

- 24 колонки в ширину. `w` ∈ {4, 6, 8, 12, 24}, `x` ∈ {0, 4, 6, 8, 12, 16, 18, 20}.
- Высота панели — `h` ∈ {3, 4, 6, 7, 8, 9, 10, 11}. Для таблиц обычно `h=8`, для stat-панелей `h=4`, для графиков `h=8` или `h=9`.
- `y` — абсолютная координата, начинается с 0.

## Row: collapsed=true vs collapsed=false

**Это КЛЮЧЕВАЯ разница, на ней ломается размещение.**

### collapsed=true

- У row есть вложенный массив `panels` (внутри объекта row).
- Все панели секции лежат ВНУТРИ row-объекта, в `row.panels`.
- `gridPos.y` у внутренних панелей — абсолютный, но **не влияет на top-level layout** пока row свёрнут. Row занимает только 1 строку на top-level.
- Первый ряд панелей внутри row обычно с `y = row.y + 1` (реже `+2`).

```json
{
  "type": "row",
  "title": "Share Groups",
  "id": 145,
  "collapsed": true,
  "gridPos": {"h": 1, "w": 24, "x": 0, "y": 109},
  "panels": [
    {"id": 147, "title": "...", "gridPos": {"h": 8, "w": 12, "x": 0, "y": 110}, ...},
    {"id": 136, "title": "...", "gridPos": {"h": 8, "w": 12, "x": 12, "y": 110}, ...}
  ]
}
```

### collapsed=false

- У row пустой `panels` массив (или его нет).
- Панели секции лежат на **top-level** дашборда (`d.panels`), следом за row-объектом.
- `gridPos.y` абсолютный, идёт подряд после `row.y`.

```json
{"type": "row", "title": "Consumer Lag", "id": 101, "collapsed": false,
 "gridPos": {"h": 1, "w": 24, "x": 0, "y": 60}, "panels": []},
{"id": 133, "title": "Consumer group", "gridPos": {"h": 3, "w": 10, "x": 7, "y": 61}, ...},
{"id": 104, "title": "Message in per minute", "gridPos": {"h": 9, "w": 12, "x": 0, "y": 64}, ...},
...
```

## Алгоритм добавления панели

1. Найти целевой row, посмотреть `collapsed`.
2. Если `collapsed=true`:
   - Добавить панель в `row.panels` (внутрь row-объекта).
   - `y` — любой разумный (например `row.y + 1`). Пользователь подвинет.
3. Если `collapsed=false`:
   - Добавить панель в `d.panels` (top-level) сразу после row-объекта.
   - `y` — любой. Пользователь подвинет.
4. **Не пересчитывать y соседей.** Пользователь расставляет позиции в UI Grafana и сохраняет обратно в файл.

## Типичные ошибки

1. **Положил панель в top-level, думая что она в секции collapsed=false row, но забыл что следом идёт collapsed=true row с большим y-разбросом внутренних панелей.** На top-level collapsed=true row занимает только 1 строку, но его внутренние панели имеют абсолютные y, которые могут пересекаться с top-level панелями — Grafana при расширении row'а может нарисовать криво.

2. **Думал что y внутри row-panels это локальные координаты.** Нет, они абсолютные. Если row на y=109, первая панель внутри обычно на y=110 (а не y=1).

3. **Пересчитывал y всех следующих панелей чтобы «освободить место» под новую.** Не надо — пользователь делает это мышкой в UI.

4. **Ставил панель с h=24 вместо w=24.** h это высота (1-12 обычно), w это ширина (1-24).

## Как найти последнее место в секции

Если очень нужно поставить панель в конец секции (а не просто любой y):

```python
# Для collapsed=false row — последняя панель в top-level перед следующим row
# Для collapsed=true row — max(y+h) среди row.panels
```

Но обычно не нужно — пользователь расставит сам.

## Шаблон gridPos для типичных панелей

| Тип панели | w | h | Примечание |
|---|---|---|---|
| Stat (маленькая метрика) | 4 | 4 | 6 в ряд |
| Stat широкая | 6 | 4 | 4 в ряд |
| График (time series) | 12 | 8 или 9 | 2 в ряд |
| График широкий | 24 | 8 или 9 | на всю ширину |
| Таблица | 24 | 8 | на всю ширину |
| Таблица компактная | 12 | 8 | 2 в ряд |
