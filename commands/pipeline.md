# Сценарий полной разработки и проверки (/pipeline)

Когда пользователь вызывает эту команду, выполни последовательную цепочку действий для указанной задачи или файла. Перед каждым шагом явно пиши: "=== Шаг X: [Название] ===".

## Шаг 1: Архитектурное планирование
- Активируй контекст и правила скилла `/architect` из `.claude/skills/architect/SKILL.md`.
- Проанализируй задачу пользователя, составь архитектурный план и спроектируй структуру слоев/классов.
- Если задача затрагивает не более 3 файлов и не меняет архитектуру слоёв — переходи к Шагу 2 без согласия. Иначе — спроси пользователя.

## Шаг 2: Реализация кода
- Активируй контекст и правила скилла `/developer` из `.claude/skills/developer/SKILL.md`.
- Возьми архитектурный план из Шага 1 и напиши по нему полный, готовый к продакшну код (бизнес-логику, эндпоинты, DTO/Records).

## Шаг 3: Компиляция
- Запусти `./gradlew build` (Java) или соответствующую команду сборки.
- Если сборка падает — вернись к Шагу 2, исправь ошибки и повтори. Не переходи дальше, пока код не компилируется.

## Шаг 4: Статический анализ и проверка стиля
- Активируй контекст и правила скилла `/linter` из `.claude/skills/linter/SKILL.md`.
- Проверь сгенерированный в Шаге 2 код на строгое соответствие стандартам (Java 21, var/final, Lombok, Stream API, PEP 8).
- Если найдены мелкие несоответствия, исправь их на лету до вывода финального результата.

## Шаг 5: Генерация тестового покрытия
- Активируй контекст и правила скилла `/testing` из `.claude/skills/testing/SKILL.md`.
- Для утвержденного и проверенного кода сгенерируй юнит-тесты по структуре Given-When-Then (JUnit 5 + AssertJ + Mockito или Pytest).

## Шаг 6: Запуск тестов
- Запусти `./gradlew test` (Java) или `pytest` (Python).
- Если тесты падают — исправь код или тесты и повтори. Не завершай pipeline, пока все тесты не проходят.

## Финальный вывод
Выведи краткую сводку:
1. **Создано/изменено:** список файлов с кратким описанием изменений.
2. **Линтер:** есть ли замечания (да/нет + количество). Если да — краткий список.
3. **Тесты:** проходят (да/нет + количество тестов).
